# From attention to a persistent body

This is a candidate architecture and comparison target, not a novelty claim.

## 1. Attention already looks like ephemeral wiring

A standard attention head forms

```math
A_t = softmax(Q_t K_t^T / sqrt(d)).
```

For one forward pass, `A_t[i,j]` behaves like a context-dependent effective
connection from position `j` to position `i`.

That is already much richer than a static point neuron.

But the wiring is ephemeral:

```text
current context
    -> manufacture dense routing graph A_t
    -> use it
    -> next forward pass manufactures another graph
```

There is no persistent local body associated with a token position.

## 2. Candidate factorization: slow body x fast conductance

Give each computational cell a sparse persistent support matrix `S` and let
fast state modulate only edges that physically/logically exist:

```math
A_body(t)
  = Normalize(
      S(t) odot G(q(t), x(t))
    ).
```

where

- `S(t)` is slow sparse persistent connectivity;
- `q(t)` is fast receiver state;
- `G` produces context/state-dependent conductances;
- `odot` is elementwise multiplication.

Interpretation:

```text
S
    who can strongly talk to whom at all

G(t)
    how open each available route is right now

A_body(t)
    effective momentary routing
```

This makes ordinary attention a useful limiting attacker:

```text
dense S = all ones
q reconstructed only from current context
no online structural change
    -> conventional dynamic attention-like routing
```

## 3. Dendritic compartments instead of one weighted sum

For neuron/cell `i`, divide incoming persistent edges among a small number of
local compartments `b=1...B`.

```math
u_ib(t)
 =
 phi_b(
   sum_(j in N_ib)
     S_ijb(t)
     g_ijb(q_i(t), q_j(t), x_j(t))
     x_j(t)
 ).

z_i(t)
 =
 sum_b c_ib u_ib(t).
```

The point is not literal dendritic simulation.

The computational distinction is:

```text
incoming signals
    -> several locally stateful nonlinear mixtures
    -> only then collapse toward one output coordinate
```

rather than

```text
incoming signals
    -> one scalar dot product
    -> nonlinearity
```

## 4. Separate output boundary

Let a distinct gate determine whether/how the rich local computation becomes a
broadcast event:

```math
y_i(t)
 =
 H(z_i(t), theta_i(t)).
```

`theta_i` can carry excitability/homeostatic state independently from the
dendritic/body computation.

Gate 1 uses the crudest possible binary version:

```text
H = TRANSMIT or HOLD
```

so that the distinction can be falsified before adding more physiology.

## 5. Local prediction and local instruction need not be identical signals

A cell can have a local self-supervised error

```math
e_i^pred(t)
 =
 x_i(t+1) - xhat_i(t+1)
```

and a distinct instructive / consequence signal `c_i(t)`.

Slow structure could then receive a three-factor update:

```math
Delta S_ijb
 =
 eta
 e_ijb(t)
 c_i(t)
 phi_ijb(t)
```

with eligibility `e_ijb` preserving which local event is being credited.

The important design choice is that `c_i` need not be one identical scalar
broadcast to every cell.  It may eventually be a vectorized local instructive
signal.

## 6. Effective operator

At any instant the network can still be analyzed as a matrix/Jacobian:

```math
W_eff(t)
 =
 partial y(t) / partial x(t).
```

But this matrix is generated by

```text
persistent topology S(t)
+
fast local state q(t)
+
branch nonlinearities phi
+
output/excitability state theta(t).
```

So the matrix is a **readout of the currently living operator**, not the whole
state of the machine.

This is the exact reason the old repo line kept returning to matrices and then
escaping from them again.

## 7. Scaling

If every cell had an arbitrary independent edge to every other cell, persistent
personal wiring costs `O(N^2)`.

That is not the only option.

If each of `N` cells maintains `B` compartments with `k` sparse incoming
edges per compartment,

```math
persistent edge state = O(N B k).
```

For fixed small `B,k`, this is linear in population size.

The hard question becomes:

> Can local sparse bodies plus fast state recover enough of the useful
> context-dependent routing that dense attention obtains cheaply on GPUs?

If no, attention wins.

## 8. A concrete hybrid worth testing later

A GPU-friendly version does not instantiate cable compartments.

Use block-sparse tensors:

```math
U_b
 =
 phi_b(
   (S_b odot G_b(Q_t)) X_t W_b
 ).

Y
 =
 AIS_theta(
   sum_b U_b
 ).
```

Then let slow online learning alter only:

- a small edge mask / edge strengths in `S_b`;
- local state `q`;
- output threshold/gain `theta`.

This is close enough to Transformer machinery to benchmark fairly, while
preserving the three Child distinctions:

1. persistent local addressability;
2. fast internal state not reconstructed only from the token list;
3. an independently regulated output boundary.

## 9. Kill conditions

Do not continue if any of these attackers match the useful result more cheaply:

- ordinary dense attention;
- local/sliding-window attention;
- block-sparse attention;
- small SSM/Mamba-like recurrence;
- TTT layer;
- reservoir/RNN;
- explicit state-space / Markov algorithm.

The purpose is not to obtain a dendrite-shaped diagram.

The purpose is to discover whether the **slow-body x fast-conductance
factorization** buys a useful computation.
