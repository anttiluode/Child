# Antti's "instanton" — the agent-shaped shadow of a field

This note is an autopsy of the supplied `anttis-instanton.py`, not a novelty
claim and not a statement about physical instantons.

## What the code actually contains

There is no independently simulated particle after initialization.

The code initializes one localized bump in a 2-D scalar field `phi`, gives the
field an initial travelling-wave derivative, and then evolves

```math
phi_tt
  = c^2 nabla^2 phi
    + a phi
    - b phi^3.
```

The nonlinear potential is the familiar double-well / phi^4 form.

The displayed green "particle" is computed afterward as

```python
center_of_mass(max(0, phi))
```

so it is a **collective observable of the entire positive field**, not an agent
with its own equation of motion.

Periodic boundaries also enter through `numpy.roll`.

## Why the trajectory can look startlingly agent-like

A high-dimensional distributed field can reorganize through:

- wave propagation;
- interference;
- nonlinear local response;
- periodic recirculation;
- growth/shrinkage of distinct positive regions.

The center of mass projects all of that onto only two numbers:

```math
X(t)
  =
  integral x [phi(x,t)]_+ dx
  /
  integral [phi(x,t)]_+ dx.
```

When positive mass migrates between separated regions, `X(t)` can jump a
large distance even though no little green object travelled along that path.

So the interesting computational object is:

```text
distributed deterministic dynamics
        ↓
collective coordinate / order parameter
        ↓
apparently purposeful low-dimensional trajectory
```

This is closer to a **collective-coordinate** picture than to an intelligent
particle.

## Determinism does not imply simple visible motion

With an identical numerical initial condition, the trajectory is fixed.

But nonlinear distributed dynamics can amplify tiny perturbations.  A local
headless reproduction of this supplied system showed progressively growing
separation of the positive-field center-of-mass trajectories under tiny
initial perturbations.

That observation is only a numerical property of this toy; no chaos theorem is
claimed.

## Why this matters to Child

This supplies another candidate answer to "where is the operator?"

Perhaps there need not be one privileged executive unit.

A low-dimensional action/state can be an **order parameter of a much larger
interacting field**.

For a neural population:

```text
many local stateful cells
    + recurrent coupling
    + synchronization / competition
        ↓
population mode
        ↓
low-dimensional collective variable
        ↓
action / routing / decision
```

Then what appears to be "the agent" at a coarse scale may be a stable or
metastable collective coordinate of dynamics below it.

## The matrix connection

Linearizing the field/network at one moment again gives a matrix/Jacobian.

But the observed collective coordinate is generated by the full trajectory.

This reinforces the Child sentence:

> the matrix is a tangent snapshot of a living operator.

## A future falsifiable gate

Construct a recurrent population with no central controller.

Compare:

1. a hand-designed executive variable;
2. a collective order parameter extracted from local dynamics;
3. a random low-dimensional projection.

Give all three the same action interface.

Ask whether the collective variable provides more stable/useful control under
local perturbations, and whether cutting the synchronization mechanism
specifically destroys it.

If not, the "smart billiard ball" remains only an evocative visualization.
